# Example code from the Datomic documentation site #

Datomic documentation: [Datomic local setup](https://docs.datomic.com/datomic-local.html).
Just want to have some example code I can pull to my other machine, plus some other folks who weren't particularly enjoying the interactive [Max Datom tutorial](https://max-datom.com) might benefit from seeing some annotated code samples.

### Running the main file ###
* Install Clojure `clj` command line tool: [Install Clojure](https://clojure.org/guides/install_clojure)
* [Set your local storage directory](https://docs.datomic.com/datomic-local.html#storage-dir)
* [Download example data sets](https://docs.datomic.com/datomic-local.html#samples)
* From the root directory of this repo, run: `clj -M main.clj`. This will download dependencies listed in `deps.edn`.
